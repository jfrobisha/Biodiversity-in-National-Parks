# Biodiversity in National Parks

## Project overview

This project explores data about species recorded in U.S. national parks and their conservation status. The goal is to clean and analyse the data, look for patterns in species at risk, and communicate findings with clear visualisations.

## Questions explored

- How are species distributed across conservation-status categories?
- Which types of species are most likely to have a recorded conservation concern?
- How do species observations vary across parks?
- Are there patterns in the parks or species groups with more at-risk records?

## Data

The project uses National Park Service species and park-observation data supplied with the exercise. The data includes species information, conservation status, park names, and observation records.

An observation is a record in the dataset; it should not automatically be interpreted as a complete count of a species' population in a park.

## Approach

1. Inspect the datasets and check their structure and data quality.
2. Clean and prepare fields needed for analysis.
3. Summarise species and observations by conservation status, species group, and park.
4. Create plots to make the main patterns easier to compare.
5. Explain the findings and note limitations in interpreting the records.
